# Accounts, Demo Mode, Owner Test Mode and Leaderboards

## Modes

### Demo
Public visitors can play Day 1 without an account. Demo state is local only and never enters leaderboards.

### Registered player
Players may create an account with email, display name and password. Marketing email consent is stored separately and defaults off. Registered company state can sync to D1 and appear in leaderboards.

### Owner test
During development through Gold, the owner can continue using the existing local save with no login requirement. Owner test data is not required to publish to rankings.

## Leaderboards

- Top Owners: company value
- Revenue Leaders: lifetime revenue
- Profit Leaders: lifetime profit
- Most Reviewed: review count
- Best Reviewed: rating, minimum 10 reviews

This avoids a new company with one five-star review immediately topping the Best Reviewed board.

## Day 1 scenario

Day 1 intentionally begins at 17 kt E wind with:
- Morning Sandbar
- Afternoon Snorkel

Each charter receives an independent captain decision:
- Run as booked
- Move to protected water
- Cancel/reschedule

The intended expert default is to run the sandbar as booked and move the snorkel to protected water.
